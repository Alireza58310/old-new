==========================================================
  آموزش ساخت SECRET برای ویزارد (Zeus Wizard)
==========================================================

SECRET چیه؟
-----------
یه رمز دلخواه که فقط ویزارد ازش استفاده می‌کنه تا توکن کلادفلر رو
داخل «لینک خصوصی» رمزنگاری کنه (لینک یک‌کلیکی برای نصب‌های بعدی).
- پسورد پنل نیست.
- اختیاریه. اگه نذاریش فقط لینک خصوصی ساخته نمی‌شه.
- فقط روی ورکر ویزارد گذاشته می‌شه، نه روی پنل.


مرحله ۱: یه متن تصادفی بساز
---------------------------
هر کدوم از این روش‌ها (فقط یکی):

الف) توی مرورگر: F12 رو بزن > تب Console > این رو بزن و Enter:

     crypto.randomUUID() + crypto.randomUUID()

   خروجی (مثلاً 3f2a...-...-9c1e...) رو کپی کن.

ب) توی ترمینال (لینوکس / مک / Git Bash):

     openssl rand -base64 32

ج) دستی: یه متن بلند و حدس‌نزدنی، حداقل ۳۲ کاراکتر.


مرحله ۲: توی کلادفلر بذارش (ورکر ویزارد دستی/پیست‌شده)
------------------------------------------------------
1. dash.cloudflare.com  >  Workers & Pages
2. روی ورکر ویزاردت کلیک کن
3. Settings  >  Variables and Secrets  >  Add
4. Type:  Secret      (نه Text)
   Variable name:  SECRET        (دقیقاً با حروف بزرگ)
   Value:  همون متنی که ساختی
5. Deploy  (یا Save and deploy)


روش جایگزین (با wrangler)
-------------------------
داخل پوشه‌ی ویزارد:

     npx wrangler secret put SECRET

بعد متن رو وقتی خواست پیست کن.
(اگه ویزارد رو با Workers Builds از گیتهاب دیپلوی کردی، همون مسیر
داشبورد بالا رو برو؛ مقدارها با keep_vars = true پاک نمی‌شن.)


مرحله ۳: تست
------------
1. صفحه‌ی ویزارد رو باز کن، توکن بچسبون، Install بزن.
2. بعد از نصب باید کارت «Zeus Wizard private link» بیاد.
3. اون لینک رو کپی کن. دفعه‌ی بعد با همون لینک بدون توکن نصب می‌شه.

اگه کارت لینک خصوصی نیومد یعنی SECRET ست نشده یا بعد از ست کردن
Deploy نکردی.


نکات مهم
--------
- بعداً SECRET رو عوض نکن: همه‌ی لینک‌های خصوصی قبلی کار نمی‌کنن
  (باید با توکن جدید دوباره نصب کنی و لینک تازه بگیری).
- لینک خصوصی = دسترسی به اکانتت. به کسی نده.
- SECRET و توکن کلادفلر رو هیچ‌جا توی گیتهاب نذار.
- اگه SECRET رو لو دادی: مقدارش رو عوض کن و Deploy بزن؛ لینک‌های
  خصوصی قدیمی باطل می‌شن.
